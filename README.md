# Employee Management System

A Java Full Stack web application developed using **Spring Boot, Spring Security, Spring Data JPA, Thymeleaf, Bootstrap and MariaDB** to manage employee records.

## Features
- Manager authentication and login
- Add, view, update and delete employees (CRUD)
- Search employees by name or department
- Database integration using MariaDB
- Responsive user interface

## Technologies Used
- **Backend:** Java, Spring Boot, Spring MVC
- **Security:** Spring Security
- **Frontend:** Thymeleaf, HTML, Bootstrap 5
- **Database:** MariaDB
- **ORM:** Spring Data JPA, Hibernate
- **Build Tool:** Maven
- **Version Control:** Git, GitHub

## How to Run

1. Clone the repository:
   git clone https://github.com/tresamariaroy-afk/employee-management-system.git

2. Create a MariaDB database named `employee_db`.

3. Configure your local `application.properties` using `application-example.properties`.

4. Run the application on Windows:
   mvnw.cmd spring-boot:run

5. Open in your browser:
   http://localhost:8080
